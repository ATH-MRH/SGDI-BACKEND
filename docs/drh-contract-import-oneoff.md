# Préparation exceptionnelle — historique

Le mécanisme temporaire de préparation Excel a été retiré après sauvegarde du lot autorisé. Aucun contrat, employé ou document contractuel n’a été créé par cette préparation.

Les chemins de reset, l’accès temporaire RH01, les identités particulières, l’empreinte codée en dur, la reconstruction D + E et l’alias DC spécifique ont été supprimés. Les règles et permissions de l’import normal restent applicables.

La table historique conserve le périmètre autorisé, le snapshot, la session, l’empreinte et l’auteur. Les audits existants ne sont pas supprimés. Le rapport historique reste compatible avec les valeurs absentes affichées « Non renseigné ». Aucun secret ni identité réelle n’est nécessaire dans cette documentation.

Une protection sans identifiant codé en dur interdit toute création depuis les sessions ou empreintes archivées, ainsi que tout nouveau téléversement d’une empreinte archivée. Une ancienne préparation ne peut donc pas être convertie en contrat après retrait du mécanisme.

Aucune migration destructive n’est exécutée. La migration historique reste versionnée et testée. L’import normal conserve son assistant quatre étapes, les modes dates/complet, les valeurs communes, les dates individuelles, les contrôles Client/Site DC et doublons, les transactions par candidat, l’audit et le rapport CSV.
