Télécharger l’application Android

Version Android. L’application iPhone n’est pas encore disponible ; vous pouvez utiliser ce site depuis Safari.

Comment installer l’application ?
  1. Ouvrez cette page dans Chrome sur votre téléphone Android.
  2. Touchez « Télécharger l’application Android », puis ouvrez le fichier APK.
  3. Si Android le demande, autorisez Chrome à installer ce fichier. Vous pourrez retirer cette autorisation après l’installation.
  4. Ouvrez IRON Emploi et identifiez-vous avec votre numéro de téléphone.
